## 城市数据

`public/data/places.json` 来自 `geonamescache 3.0.2` 提供的 GeoNames 记录，含 34,006 个城市中心条目。GeoNames 数据采用 CC BY 4.0；geonamescache 软件本身采用 MIT，两者分别记录：

- `public/licenses/GeoNames-CC-BY-4.0.txt`：GeoNames 署名、原始数据与许可链接，以及筛选、JSON 重编排、别名归一化、中文显示名、复合标签等修改说明。
- `public/licenses/geonamescache-MIT.txt`：Python 包原始版权及许可通知。

网页现有的 GeoNames 署名应保留，公开数据及许可说明共同提供原始来源和修改信息。[GeoNames 使用条款](https://www.geonames.org/export/)与 [CC BY 4.0 条款](https://creativecommons.org/licenses/by/4.0/)允许再分发和改编，并要求署名、许可链接及修改标识。

## 历史时区

`public/data/timezones.json` 是从 `tzdata 2026.6` 内的 IANA `2026f` TZif 数据导出的浏览器表。IANA 数据的公有领域来源与 Python 包装软件的 Apache 2.0 来源分开保留：

- `public/licenses/IANA-tz-LICENSE.txt`：从 IANA 指定源库的 [2026f LICENSE](https://github.com/eggert/tz/blob/2026f/LICENSE)原样下载。声明除列明例外外，时区代码和数据属于公有领域。
- `public/licenses/tzdata-NOTICE.txt`：当前安装 tzdata 包内原始版权及许可通知。
- `public/licenses/Apache-2.0.txt`：当前 tzdata 包附带的完整 Apache 2.0 文本。

[IANA 官方来源说明](https://www.iana.org/time-zones/tz-link)将 `eggert/tz` 列为源代码仓库，并区分公有领域数据库与 Python tzdata 包的 Apache 许可；[Python 包许可](https://github.com/python/tzdata/blob/master/LICENSE)也单独列明。
